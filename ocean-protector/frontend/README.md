# OceanGuard Frontend

React + Vite + TypeScript dashboard for citizen, analyst, and authority workflows.

## Start

```powershell
npm config set registry https://registry.npmjs.org/
npm install
npm run dev
```

Open `http://localhost:5173`.

## Scripts

- `npm run dev` — Vite development server
- `npm run typecheck` — TypeScript validation
- `npm run build` — production build
- `npm run preview` — preview the production build

The frontend currently uses mock services from `src/services/index.ts`. Environment defaults are stored in `.env.example`.
